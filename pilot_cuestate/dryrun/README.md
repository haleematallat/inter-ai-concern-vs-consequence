# Dry-run artefacts — NOT RESULTS

Everything in this directory was produced by a **deterministic fake model**, not by any language model. It
is kept as evidence that the analysis pipeline ran end to end before any money was spent, and for the
design-resolution simulations.

**Do not read any figure or table here as a finding.** The real results are in `../../results/vignette/`:

- `extension.md` with `fig_cells_by_model.png`, `fig_primary_forest.png`, `fig_request_diagnostic.png`
- `confirmatory.md`, `costresponse.md` with `fig_cost_response.png`, `calibration.md`, `plausibility.md`

The one exception is `vignette/power_audit.md` and `power_audit.csv`, which are simulations by design and
are reported as such.
